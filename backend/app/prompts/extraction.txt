Выдели требования из документа, заданного списком фрагментов с ID.

Требование — утверждение, которое что-то предписывает, ограничивает или определяет: функция, правило, предел, формат, шаг логики, параметр API, код ответа, критерий приёмки, данные для хранения, срок, строка контракта API (метод, URL, описание, авторизация).
Не требования: служебные сведения (автор, согласующие, название задачи), пункты пустого шаблона ревью, чисто поясняющий текст.

Правила:
- Указывай ТОЛЬКО ID фрагментов из списка. Текст требования система возьмёт сама.
- Обычно один фрагмент — одно требование. Объединяй несколько, только если по отдельности они не имеют смысла (заголовок или код статуса и пример ответа ИМЕННО этого кода). Разные коды, поля, шаги и правила не объединяй.
- Один фрагмент входит не более чем в одно требование. Не пропускай требования вне нумерованных списков.
- summary — краткая формулировка до 15 слов, без добавления смысла.
- requirement_type и уверенность классификации (0..1).
